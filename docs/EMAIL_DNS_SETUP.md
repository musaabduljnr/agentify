# Email DNS setup for agentifychat.online

These records must be added at the DNS provider for `agentifychat.online`.
Replace every `<...>` placeholder with the value from your email provider.
DKIM selectors and values are unique per provider/domain and cannot be guessed.

## 1. Mailboxes

Create the two mailboxes (or aliases) at your email provider:

- `support@agentifychat.online`
- `sales@agentifychat.online`

Point the domain's MX records at that provider. Example for Google Workspace:

| Type | Name | Priority | Value |
| --- | --- | --- | --- |
| MX | @ | 1 | smtp.google.com |

Example for Microsoft 365:

| Type | Name | Priority | Value |
| --- | --- | --- | --- |
| MX | @ | 0 | agentifychat-online.mail.protection.outlook.com |

## 2. SPF

One SPF record per domain. Merge include mechanisms if you send through more than one provider.

| Type | Name | Value |
| --- | --- | --- |
| TXT | @ | `v=spf1 include:_spf.resend.com include:_spf.google.com ~all` |

Only include the providers you actually use. Remove unused includes.

## 3. DKIM

Add the DKIM records generated by your sending provider. Never reuse a selector from
another domain.

Resend example:

| Type | Name | Value |
| --- | --- | --- |
| TXT | `resend._domainkey` | `<DKIM_PUBLIC_KEY_FROM_RESEND>` |

Google Workspace example:

| Type | Name | Value |
| --- | --- | --- |
| TXT | `google._domainkey` | `v=DKIM1; k=rsa; p=<DKIM_PUBLIC_KEY_FROM_GOOGLE>` |

## 4. DMARC

Start in monitor mode, then tighten after reviewing reports.

| Type | Name | Value |
| --- | --- | --- |
| TXT | `_dmarc` | `v=DMARC1; p=none; rua=mailto:dmarc@agentifychat.online; adkim=s; aspf=s; pct=100` |

After 2-4 weeks of clean reports, move to `p=quarantine`, then `p=reject`.

## 5. Verification

```bash
nslookup -type=TXT agentifychat.online
nslookup -type=TXT _dmarc.agentifychat.online
nslookup -type=TXT resend._domainkey.agentifychat.online
nslookup -type=MX agentifychat.online
```

Then send test messages to both mailboxes and confirm delivery, SPF pass, DKIM pass,
and DMARC pass in the message headers.
